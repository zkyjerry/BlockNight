# 体验重构 02 · 午夜暗房

依据 2026-09-08 的六点实际试玩反馈。此文优先于上一版规则，完成后同步主设计文档。

## 核心修正

9×9棋盘保持。玩家与敌人的逻辑位置只能为整数格心；普通运动是格到格短促过渡，不能沿任意角度游走。WASD单次按下只走一格，不攻击；Shift朝当前面向贯穿到边界，Shift+方向直接指定冲斩方向。按住方向可按固定间隔重复步进，但不影响单击只走一格。冲斩仍沿整条格线逐格判定击杀。敌人有各自的步进节拍，格心之间的动画仅属表现，不影响占格。

## 主题与节奏

午夜暗房：在一张9×9接触印样上切开游影，保住最后一卷底片。普通战斗为墨黑、骨白、暗房朱红和少量药液金；凝时切到冷青负片，敌人冻结为待显影的曝光轮廓，结束时快门闭合→显影爆裂。回溯使用紫灰磁带倒转、横向扫描与反向拖影。避免多种霓虹同时争夺注意。

音乐从泛用电子loop改为低速暗房机械脉冲：磁带噪声底、低频心跳、金属快门节拍和稀疏小调钟音。随进度逐步加入节拍层。凝时将主乐压低/低通/降速，加入持续凝滞低音；结束停止低音并击发快门重音。回溯为反向磁带扫频，区别于凝时。

## 界面

战斗中央棋盘；顶端只显示分数与剩余局时；底端只显示两个技能键/就绪状态与细成长进度。连杀和显影仅短暂出现。不常驻游戏标题、宣传语、所有操作说明、击杀统计或每种敌人说明。

标题、暂停和结算承担说明、重玩和设置；三选一只显示强化名、效果和快捷键。全部中文，捆绑开源字体，不依赖机器安装字体。

首次提供可跳过的4步交互教学：移动一格→冲斩→凝时蓄积与释放→回溯改变位置。每次只呈现当前操作提示；教学无随机死亡；完成或跳过后回到正常的五分钟挑战。

## 验收

- 任意时刻玩家/敌人的逻辑坐标为整数；追猎者一次只改变一个轴且最多一格。
- 无Shift的WASD只走一格，不击杀；任何内部格都可以到达；Shift完成贯穿斩杀。
- 游戏内不存在英文说明或中文缺字；1280×720及1600×1000均无裁切。
- 战斗界面仅分数/时间/2技能/成长进度，教学提示仅在教学出现。
- 凝时与正常模式在静帧上明显可分，在声音参数上体现主乐衰减、低通和独立凝滞层；结束有独立释放。
- 教学按实际操作推进，且可跳过；不借助QA入口也能学会并开始游戏。
- 普通战斗、凝时、回溯、强化、死亡、重开保持可运行；更新规则回归与独立程序。
