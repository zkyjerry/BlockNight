## 自动测试范围

`Block Night/Run Acceptance Tests` 运行独立模型。五分钟测试使用显式保护以验证终局与状态界限，只证明技术流程，不证明玩家难度平衡。运行集成和视听检查另外记录。

## 迭代记录

### 第一轮：规则和完整循环

实现固定步长模拟、碰撞、悬置结算、完整世界快照、8强化/4敌人、五分钟终局，分离表现与音频。验证结果待运行后更新。

### 第二轮：实际运行暴露的问题

1. 相机仅清除棋盘区域，导致外侧保留旧菜单/闪光。增加全屏背景相机，截图确认无残留。
2. 一冲到底使路线最终收缩到外圈。增加 Shift 沿边步进，仍保留普通 WASD 到底；新增内部选线测试。
3. 桥接注入的按键边沿与旧输入接口不兼容。统一 Input System，并用帧间按下状态检测技能边沿；Enter、W、Q、数字1已在运行序列中生效。允许后台渲染，失焦依然暂停正常战斗。
4. 1600×1000 的长卡片末行溢出。正文从21降到18，重拍确认三张卡的按键提示与说明完整；修正余震首级范围说明为1.05格。
5. 回溯时残留「释放」浮字。施放回溯时改为紫色 REWIND 提示，并清掉前向残像/碎片。
6. 慢时恰好结束的帧可能新挂起一个敌人而无法结算。切换该帧的判定为普通击杀，并加入专门回归测试。

### 最终规则回归

**17/17 PASS**，详见 [原始结果](Evidence/model-tests.txt)。包含完整五分钟刷新模拟、深复制、技能防连发、满级溢出奖励、干净重开和慢时结束边界帧。最后一轮编译错误数为0。

## 当前结论与真人验收

功能、规则和界面布局达到 Demo 的可执行验收标准。心流与主观爽感、音效听感尚无真人样本，不能宣布全部体验指标已证明。下一轮真人试玩应按设计文档的5人样本方案，记录死亡时刻、原因、技能使用和压力评分，再据数据调整出生间隔/预警/技能冷却。
