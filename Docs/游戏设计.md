# 方块战士 / BLOCK / NIGHT

版本：Demo 1，2026-09-08。定位：单局 3–8 分钟的霓虹棋盘动作肉鸽。核心体验为观察预警 → 连续转向穿杀 → 撞墙结算 → 争取下一次强化；时间技能提供主动规划与失误修正。

## 操作与规则
- WASD / 方向键：从静止起冲，冲刺中即时转向；只有撞到边界结束斩击链。棋盘中心坐标 ±5，玩家半径 0.18，速度 13 单位/秒。
- 路径使用线段距离命中，防止高速度穿透敌人。接触敌人不致死，只有已生效攻击致死。
- Space：时间折叠，持续 2.6 秒，世界速度 18%，玩家速度不变，冷却 11 秒（释放结束才开始）。死亡敌人立即失去攻击能力，裂解残影停留，到慢时间结束统一爆发。
- Q：回溯最近最多 3 秒，倒带播放 0.85 秒；冷却 16 秒。至少积累 0.5 秒历史才能释放。回溯结束有 0.55 秒安全期。
- 回溯恢复玩家位置、方向、敌人、子弹、波次计时、分数、连击、强化进度、随机数状态。技能冷却不回溯，防止无限回溯；强化选择后清空历史以防跨强化复制收益。
- 一次攻击即死亡；命中后有 0.6 秒濒死回溯窗口，此时不能移动，只能 Q。窗口结束后死亡结算，可重开或返回标题。
- Esc 暂停；M 静音；三选一支持鼠标与 1/2/3。暂停、标题、强化选择、倒带不推进战斗计时。

## 奖励与成长
每个敌人基础 100 分，链内第 n 次击杀为 100 × (1 + 0.25 × min(n−1,12))；撞墙额外奖励 25 × n²，形成长链目标。慢时间只是延迟视听释放，逻辑奖励立刻结算。

下一次强化初始 30 秒，随时间自然减少；每击杀减少 1.2 秒，每次撞墙长链再减 min(3, 0.2n)。进度为主 HUD 最大信息。进度归零暂停战斗，随机展示三个不同且未满级选项。强化后下一周期 30 秒，最多三层；所有强化满级后提供积分补给。

| 强化 | 每层效果 | 上限 / 目的 |
|---|---|---|
| Overdrive 超驱 | 冲刺速度 +12% | 3 层，机动 |
| Wide edge 宽刃 | 斩击半径 +0.08 | 3 层，容错 |
| Time well 时井 | 慢时间 +0.6 秒 | 3 层，控场 |
| Fast charge 快充 | 慢时间 CD −1.5 秒 | 3 层，技能流 |
| Deep memory 深忆 | 回溯 CD −2 秒 | 3 层，容错 |
| Momentum 动量 | 击杀推进强化 +0.35 秒 | 3 层，成长流 |
| Compound 复利 | 所得积分 +25% | 3 层，高分流 |
| Quiet world 静域 | 世界慢速倍率 −0.04 | 最低 0.06，控场 |
| Afterimage 残像 | 回溯后安全期 +0.25 秒 | 3 层，救险 |

## 敌人与难度
所有刷新有 1.2 秒空心轮廓预警；最早攻击在刷新完成后至少 1 秒。生成距离玩家至少 1.7 单位。敌人池上限 36，弹幕上限 80，满池跳过生成。

| 类型 | 形状 / 色彩 | 行为与预警 |
|---|---|---|
| Sentinel 哨兵 | 珊瑚红方块 | 周期瞄准，细线锁定，发射单弹 |
| Prism 棱镜 | 紫色菱形 | 四方向发射，十字预警 |
| Hunter 猎手 | 琥珀三角 | 沿方向追踪，每轮发射较慢弹 |
| Pulse 脉冲 | 粉色圆形 | 显示扩散危险圈，再发射八向弹 |

前 20 秒以哨兵为主，随后解锁棱镜，40 秒猎手，60 秒脉冲。生成间隔 max(0.65, 2.2−t/100)，弹速 min(4.2, 2.0+t/120)。攻击周期至少 1.5 秒，预警至少 0.7 秒。每 45 秒周期最后 7 秒为休整，生成间隔 ×1.8；怪物数量随时间递进但有硬上限，给玩家周期喘息。心流是设计假设，须以试玩中的死亡频率与主观挑战感验证，不宣称公式自动保证。

## 教学
独立安全教学模式，不推进生存时间或刷新：1 移动撞墙；2 击杀指定目标；3 激活慢时间；4 积累历史并实际回溯；5 进入正式局。文字持续显示操作，已知操作可跳过。主菜单可随时重新进入。

## 视听规范
深海黑底、青色玩家、珊瑚敌方、紫色时间技能；形状编码补充颜色编码。主棋盘为世界 SpriteRenderer 网格，HUD 使用 Canvas。URP Volume 控制 Bloom、色差、暗角、色彩偏移；Cinemachine Impulse 控制短促震动；ParticleSystem 击杀碎片，DOTween 按钮悬浮和点击、击杀／奖励反馈。慢时间降低音调并延后击杀爆破；回溯用紫色偏移、世界反向位移、轨迹和下降音阶表达。音乐采用原创程序合成循环，危险随生存时间增加节奏声部；音量留出击杀瞬态余量，支持 M 静音。

## 架构与编辑
纯 C# CombatModel 负责确定性战斗和快照；GameDirector 协调状态；ArenaPresentation 负责世界对象、Volume / Cinemachine / 粒子；GameHUD 管理面板和文案；SynthAudio 负责合成音频；DemoBuilder 仅编辑器构建并持久化场景，不进入运行时。敌人与弹幕使用场景预置池，静态棋盘不在运行时生成。数值配置作为独立 ScriptableObject 保存，可在 Inspector 调整。编辑器菜单 Block Night/Build Demo 重建场景，执行前应保存手工调整（重建会替换 Demo 场景）。

## 验收标准（构建前制定）
1. 完整度：标题、教学、战斗、暂停、三选一、濒死、倒带、死亡、重开全部可达；4 敌型、9 强化可用。
2. 移动：四向边界停止误差 ≤0.001 单位；单帧高速穿过目标必命中；只在撞墙结算链。
3. 时间：慢时间内玩家位移不变，世界推进 18%（基础值）；倒带目标误差 ≤0.1 秒；倒带恢复实体/弹幕/奖励/随机状态；CD 不回退。
4. 攻击：刷新预警 ≥1.2 秒，攻击预警 ≥0.7 秒；命中一次即进入濒死，不存在多血量。
5. 成长：每次提供 3 个互异未满级选项，最多 3 层；击杀准确减少倒计时，选择时世界不动。
6. 视觉：1600×1000 与 1280×720 截图无遮挡；棋盘、倒计时、两技能 CD、敌人轮廓可辨；慢时间和倒带截图色调有明显差异；连击粒子数量从 12 增至最多 72，震动幅度从 0.04 增至最多 0.22。
7. 技术：C# 编译错误 0，运行异常 0；自动确定性模拟至少 10,000 帧，无 NaN、出界、超池；死亡、倒带、强化状态有针对性断言；场景磁盘中保存网格、相机、UI、灯、玩家与对象池。
8. 性能：实体池 ≤36，弹幕 ≤80，历史 ≤80 帧；快照 20 Hz。编辑器截图检查与逻辑测试不等同于目标设备性能，实际 ≥60 FPS 留待用户设备试玩验证。
9. 人工试玩：教学无需口头解释即可完成；3 分钟内至少 3 次强化；长链与普通击杀反馈差异明显；慢时间释放与倒带都可在不读文字时辨认；连续 3 局无体验阻塞。手感／音乐舒适度由用户验收。
