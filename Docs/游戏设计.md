# 方块战士：当前游戏设计

版本：6 · 2026-09-09。本文为当前规则；历史方案存放在 `Backups/legacy-docs`，不再覆盖本文。Demo 为无尽生存，目标是连续斩杀、加速强化并刷新单局成绩。主观手感与心流仍需真人试玩验证。

## 棋盘与操作

棋盘固定 8×8，逻辑格坐标 0…7；格心世界位置为 `(格坐标−3.5)×1.375`。棋盘、玩家、敌人、格子冲击波均由世界对象呈现，HUD 使用 Canvas。所有文字使用 TextMeshProUGUI，统一采用用户提供的 FZXIANGSU12 字体生成的 TMP 字体资源。

| 输入 | 行为 |
|---|---|
| WASD / 方向键，静止时 | 不同朝向只原地转身；相同朝向走一格，普通走格不能击杀 |
| J | 沿朝向持续冲刺斩击，当前配置速度 11 格/秒 |
| 冲刺中 WASD | 可改变冲刺方向；格间移动时记录最后一次方向，到下一格心生效，不斜切格子 |
| K | 时间折叠，冲刺中也可使用 |
| L | 时间回溯；正在斩击时锁定，命中进入濒死后可自救 |
| Esc / M | 暂停或继续 / 静音，静音状态跨场景保持 |
| 1、2、3 / 鼠标 | 选择强化 |

普通走格速度 7 格/秒；每次按下处理一次，不自动连走，走格中忽略新移动请求。冲刺允许连续转弯，包括反向；J 不能重复触发或主动收刀。沿当前方向走出棋盘时才结束整条连斩；在边缘格心及时转向仍可继续。基础冲刺转向等待最多约 0.091 秒。敌人只在格心生成，猎手只跳相邻空格。敌人的撞击与冲击波均作用于格子；接触静止敌人本体不会死亡，进入已生效的危险格一次即进入濒死。

## 时间技能

| 技能 | 基础数值 | 使用限制与反馈 |
|---|---|---|
| 时间折叠 | 持续 2.6 秒；世界倍率 0.18；结束后冷却 11 秒 | 玩家不减速。敌人动作、格子冲击波与阶段刷新一起减慢；斩杀立即停止敌人攻击并给予奖励，裂解残影在技能结束集中爆发。蓝青色调、色差、低音调表达滞后 |
| 时间回溯 | 回到最近最多 3 秒；0.85 秒倒带；冷却 16 秒；回溯后保护 0.55 秒 | 至少约 0.5 秒历史；冷却不回溯。恢复玩家格子、朝向、转向队列、移动插值、敌人及格子攻击、阶段与刷新计时、积分、连斩、强化进度、随机状态。紫色调与实体连续逆向运动表达倒带 |

命中后冻结战斗 2 秒，显示 L 自救提示；窗口结束后进入独立失败场景。回溯期间不接受新操作。技能有效时间与冷却按现实游戏秒计，暂停和选牌不推进；阶段与敌人攻击按世界秒计。强化选择后清空历史，防止跨强化重复领奖。回溯不恢复慢时间持续状态；已悬置目标在倒带结束时释放。

## 击杀与成长

链内第 n 杀积分为 `round(100×(1+0.25×min(n−1,12))×(1+0.25×复利层数))`；收刀额外奖励 `25×n²`。7 连杀且没有积分强化时总分为 2,450。只有完成斩击才更新最佳连斩和收刀奖励。

顶部保留数字，棋盘外围粗进度环从上边中点开始逆时针消退，宽 0.115 世界单位；击杀时加宽到 0.19 并闪亮，再衰减：每轮强化当前配置初始 60 秒，自然流逝；每击杀额外推进 1.2 秒，收刀再推进 `min(3,0.2n)` 秒。击杀以进度条弹动反馈推进。归零后等待当前斩击结束再暂停并弹出三选一，避免选牌打断操作。选择后下一轮按 Balance.upgradeSeconds 重置（当前 60 秒）。

| 强化 | 每层效果（护盾除外，最多三层） |
|---|---|
| 超驱 | 冲刺速度 +12% |
| 轻步 | 普通走格速度 +20% |
| 时井 | 时间折叠持续 +0.6 秒 |
| 快充 | 折叠冷却 −1.5 秒，最低 4 秒 |
| 深忆 | 回溯冷却 −2 秒，最低 6 秒 |
| 动量 | 每杀额外推进强化 0.35 秒 |
| 复利 | 击杀积分 +25%，不影响收刀奖励 |
| 静域 | 世界慢速倍率 −0.04，最低 0.06 |
| 残像 | 回溯后保护 +0.25 秒 |
| 护盾（最多持有一个） | 冲刺中免疫一次任意方向伤害，圆环包裹玩家；消耗后可再次从强化获得 |

护盾只在冲刺时生效，抵挡来自任意方向的一次格子撞击或冲击波伤害。普通走格和静止时不生效。消耗时圆环碎裂，该次攻击被阻断；同帧第二次攻击仍可造成死亡。未消耗时收刀收起，下一次冲刺再次展开。护盾不会自动恢复，也不能通过回溯返还。持有护盾时不出现护盾词条；消耗后才重新加入候选池，重新选择获得一个，不能叠加。

候选未满级强化互不重复；候选不足三项时空位为积分补给（+2,500），全部满级时三张均为补给。

## 敌人及分阶段刷新

移除自由飞行弹丸。撞击型敌人预警下一格，再整体移入该格并产生短暂撞击；冲击波型敌人沿对角线逐格激活危险区，每次推进前都预警下一格，同时按独立周期斜向移动。

| 类型 | 形状 / 颜色 | 默认行为 | 攻击间隔 / 预警 |
|---|---|---|---|
| 突进方卫 | 方块 / 金黄 | 向右撞击一格，到边界反向 | 2.4 / 0.65 秒 |
| 斜波棱镜 | 菱形 / 紫 | 右上冲击波 4 格；每 3.2 秒尝试右上移动一格 | 2.8 / 0.65 秒 |
| 巡格猎手 | 三角 / 米白 | 向上撞击一格，到边界反向；不锁定追踪玩家 | 2.0 / 0.55 秒 |
| 逆波脉冲 | 圆 / 绿 | 左上冲击波 5 格；每 4 秒尝试左上移动一格 | 3.2 / 0.65 秒 |

每类敌人使用 `Data/Enemies` 下独立 EnemyDefinition SO。属性包括行为、方向、出生预警、攻击间隔、攻击预警、危险格持续时间、边界反向；冲击波型另有移动间隔、移动预警、传播格数和每格预警。

默认出生预警 1.2 世界秒，斜波移动预警 0.6 秒。第一格使用敌人的攻击预警；后续每格预警 0.28 秒，激活持续 0.16 秒，最后一格或边界处结束。每次敌人位移只能到一个相邻格；格心坐标保持精确，不叠在其他敌人上。攻击和移动预警互不打断，冲突时顺延并保留完整预警。玩家可以在预警期走过目标格，危险区生效后进入即受击。

生成避开玩家格及曼哈顿距离不足 2 的格，批内不重叠；敌人池 36、格子攻击池 80，容量不足跳过多余生成。攻击强度由各敌人 SO 明确控制，不再使用随时间隐式增加的弹速公式；阶段变化负责数量与组合压力。

`Assets/BlockNight/Data/SpawnSchedule.asset` 的列表顺序决定阶段。每阶段独立配置名称、持续秒数、每批数量、敌人种类、刷新间隔。进入阶段立即刷一批；阶段切换重置刷怪计时，不清除存量敌人。种类从允许列表随机选择，重复条目增加权重；数量为 0 或列表为空时不生成。

| 默认阶段 | 持续世界秒 | 每批 | 间隔世界秒 | 种类 |
|---|---:|---:|---:|---|
| 入阵 | 25 | 3 | 3.0 | 突进方卫 |
| 交锋 | 35 | 3 | 2.7 | 方卫、棱镜 |
| 游猎 | 40 | 3 | 2.4 | 棱镜、猎手 |
| 脉冲 | 45 | 4 | 2.4 | 全部 |
| 压力 | 35 | 5 | 2.2 | 全部 |
| 喘息 | 30 | 5 | 2.0 | 不生成 |
| 极限 | 60 | 5 | 1.8 | 全部 |

喘息阶段目前种类列表为空，因此不生成敌人，即使每批数量填写为 5。以上表格保留用户最新调整。

默认最后阶段持续执行；关闭“结束后持续最后阶段”则整个列表结束后停止刷新，已有敌人仍活动。时间折叠延缓阶段推进，回溯恢复当时的阶段。压力与休整是可调节奏设计，不代表已经通过心流验证。

## 反馈规范

| 当前斩击击杀数 | 名称 | 每杀碎片 | DOTween 镜头位移震幅 | 震动秒数 | Vignette 亮角强度 |
|---|---|---:|---:|---:|---:|
| 1–2 | 破阵 | 64 | 0.10 | 0.140 | 0.16 |
| 3–4 | 连破 | 110 | 0.18 | 0.205 | 0.27 |
| 5–6 | 狂斩 | 180 | 0.28 | 0.270 | 0.40 |
| ≥7 | 极斩 | 280 | 0.40 | 0.335 | 0.55 |

Particle System 径向碎片、扩散冲击环、玩家形变、Bloom 爆闪及连斩音高共同提升。DOTween 直接驱动 Main Camera，棋盘和 Canvas Transform 不参与震动，完成后恢复基准位置；正常战斗时 Cinemachine 不写入；濒死时独立虚拟相机接管，恢复完成后归还 DOTween。Vignette 使用 HDR 青色 `(1.5,12,8)` 产生真实亮角，普通 ≤1 颜色只会压暗。连斩峰值保留约 0.8 秒余韵后衰减。

深色背景、青色玩家、金黄、紫、米白、绿敌人，形状区分类型；技能特效保留敌人轮廓。UI 沿用用户排版，按钮悬浮与点击使用 DOTween。主菜单与失败页全部使用静态 TMP 文字，已移除 TextAnimator 组件，插件保留供后续人工调整。攻击、移动撞击及冲击波的危险格统一红色；出生提示使用敌人自身的非红色与对应形状，避免混淆。程序合成音乐从 92 向 142 BPM 递增，25/65 秒增加声部；击杀、收刀、选择、折叠、倒带、死亡使用不同音效。最终听感需试听。

## 教学与页面

`MainMenu` 提供进入棋盘及新手引导；`BlockNight` 承载战斗、七步教学、暂停与强化；`GameOver` 展示成绩、重开与返回主界面。三者均为独立保存的场景。教学与战斗共用规则：转向→走格→斩击→折叠→等待释放→回溯→正式战斗；教学暂停自然刷怪与攻击，可随时跳过。

验收结果及待真人确认项见《验收报告》，编辑入口见《使用与微调》。

## v6 反馈与实验范围冲击波

选择强化后可释放范围冲击波，由 `Data/FeedbackSettings.asset` 的 `upgradeShockwave` 开关控制，默认开启；`shockwaveRadius` 为最大半径，单位是格，默认 4；`shockwaveSeconds` 为扩散时间，默认 0.65 秒。以释放时的玩家位置为圆心，范围内及边界上的敌人计为击杀，范围外保留；顺序计分使用同一击杀公式，推进下一轮倒计时。冲击波本身不计为玩家斩击，不追加收刀奖励。范围内危险格随波清除，扩散期间给予短暂保护。

圆环抵达指定半径后隐藏，沿终点圆周发射 `clamp(ceil(半径×64),128,768)` 枚粒子，向外散开并在 0.35–0.7 秒内淡出；每次扩散仅触发一次。原点、当前半径、最大半径和扩散时长均进入回溯快照，粒子不重复计分。修改 SO 不会改变已释放波的半径。

护盾破碎增强为 220 枚碎片、两圈扩散环、0.32 秒 / 0.28 位移震动，并触发 Bloom 和亮角反馈。敌人本体与出生均避开红色和玩家蓝青色；攻击预警框在预警时间内由 20% 增长至整格，冲击波危险格也按自身预警进度增长。

濒死 Vignette 强度 0.62，颜色深红 `(0.23,0.005,0.018)`；Cinemachine 虚拟相机在 0.25 秒内聚焦玩家，正交 Size 从 7.7 缩至 4.6。L 回溯时用 0.35 秒恢复镜头；回溯结束恢复常态后处理。濒死窗口当前为 2 秒，可在反馈 SO 调整。

技能 CD 从正数归零时，K 闪青绿光，L 闪紫光，时长 0.42 秒，峰值 alpha 0.14；归零后不会每帧重复闪烁，暂停和选牌不会推进 CD。字体图集已重新预生成 415 个现用字形并保存，避免动态字符表与图集不同步造成的旧字缺失。
