# 方块战士：当前游戏设计

版本：3 · 2026-09-09。本文为当前规则；历史方案存放在 `Backups/legacy-docs`，不再覆盖本文。Demo 为无尽生存，目标是连续斩杀、加速强化并刷新单局成绩。主观手感与心流仍需真人试玩验证。

## 棋盘与操作

棋盘固定 8×8，逻辑格坐标 0…7；格心世界位置为 `(格坐标−3.5)×1.375`。棋盘、玩家、敌人、弹幕均由世界对象呈现，HUD 使用 Canvas。所有文字使用 TextMeshProUGUI，统一采用用户提供的 FZXIANGSU12 字体生成的 TMP 字体资源。

| 输入 | 行为 |
|---|---|
| WASD / 方向键，静止时 | 不同朝向只原地转身；相同朝向走一格，普通走格不能击杀 |
| J | 沿朝向持续冲刺斩击，基础速度 13 格/秒 |
| 冲刺中 WASD | 可改变冲刺方向；格间移动时记录最后一次方向，到下一格心生效，不斜切格子 |
| K | 时间折叠，冲刺中也可使用 |
| L | 时间回溯；正在斩击时锁定，命中进入濒死后可自救 |
| Esc / M | 暂停或继续 / 静音，静音状态跨场景保持 |
| 1、2、3 / 鼠标 | 选择强化 |

普通走格速度 7 格/秒；每次按下处理一次，不自动连走，走格中忽略新移动请求。冲刺允许连续转弯，包括反向；J 不能重复触发或主动收刀。沿当前方向走出棋盘时才结束整条连斩；在边缘格心及时转向仍可继续。基础冲刺转向等待最多约 0.077 秒。敌人只在格心生成，猎手只跳相邻空格。弹幕连续运动。接触敌人本体不会死亡，生效弹幕命中一次即进入濒死。

## 时间技能

| 技能 | 基础数值 | 使用限制与反馈 |
|---|---|---|
| 时间折叠 | 持续 2.6 秒；世界倍率 0.18；结束后冷却 11 秒 | 玩家不减速。敌人与弹幕、阶段刷新一起减慢；斩杀立即停止敌人攻击并给予奖励，裂解残影在技能结束集中爆发。蓝青色调、色差、低音调表达滞后 |
| 时间回溯 | 回到最近最多 3 秒；0.85 秒倒带；冷却 16 秒；回溯后保护 0.55 秒 | 至少约 0.5 秒历史；冷却不回溯。恢复玩家格子、朝向、转向队列、移动插值、敌人及弹幕、阶段与刷新计时、积分、连斩、强化进度、随机状态。紫色调与实体连续逆向运动表达倒带 |

命中后冻结战斗 0.6 秒，显示 L 自救提示；窗口结束后进入独立失败场景。回溯期间不接受新操作。技能有效时间与冷却按现实游戏秒计，暂停和选牌不推进；阶段与弹幕按世界秒计。强化选择后清空历史，防止跨强化重复领奖。回溯不恢复慢时间持续状态；已悬置目标在倒带结束时释放。

## 击杀与成长

链内第 n 杀积分为 `round(100×(1+0.25×min(n−1,12))×(1+0.25×复利层数))`；收刀额外奖励 `25×n²`。7 连杀且没有积分强化时总分为 2,450。只有完成斩击才更新最佳连斩和收刀奖励。

顶部中央倒计时是最显眼的目标：每轮强化初始 30 秒，自然流逝；每击杀额外推进 1.2 秒，收刀再推进 `min(3,0.2n)` 秒。击杀以进度条弹动反馈推进。归零后等待当前斩击结束再暂停并弹出三选一，避免选牌打断操作。选择后下一轮重置为 30 秒。

| 强化 | 每层效果（最多三层） |
|---|---|
| 超驱 | 冲刺速度 +12% |
| 轻步 | 普通走格速度 +20% |
| 时井 | 时间折叠持续 +0.6 秒 |
| 快充 | 折叠冷却 −1.5 秒，最低 4 秒 |
| 深忆 | 回溯冷却 −2 秒，最低 6 秒 |
| 动量 | 每杀额外推进强化 0.35 秒 |
| 复利 | 击杀积分 +25%，不影响收刀奖励 |
| 静域 | 世界慢速倍率 −0.04，最低 0.06 |
| 残像 | 回溯后保护 +0.25 秒 |

候选未满级强化互不重复；候选不足三项时空位为积分补给（+2,500），全部满级时三张均为补给。

## 敌人及分阶段刷新

删除锁定玩家的射击机制，所有弹幕均为固定斜向；攻击预警线与实际弹幕共用方向数据。

| 类型 | 形状 / 颜色 | 攻击 |
|---|---|---|
| 双斜射手 | 方块 / 珊瑚红 | 左上 + 右下 |
| 四斜棱镜 | 菱形 / 紫 | 四个斜向 |
| 跃格猎手 | 三角 / 琥珀黄 | 右上 + 左下；预警前每 1.3 世界秒尝试朝玩家跳一格，不能与其他敌人重叠或跳入玩家格 |
| 交替脉冲 | 圆 / 粉 | 左上 + 右下，与右上 + 左下交替 |

每次出生预警 1.2 世界秒，攻击前 0.7 世界秒显示方向线。生成避开玩家格及曼哈顿距离不足 2 的格，批内不重叠；敌人池 36、弹幕池 80，容量不足跳过多余生成。敌人攻击间隔 `max(1.5,3.2−t/160)`，弹速 `min(3.5,1.6+t/140)` 格/世界秒。

`Assets/BlockNight/Data/SpawnSchedule.asset` 的列表顺序决定阶段。每阶段独立配置名称、持续秒数、每批数量、敌人种类、刷新间隔。进入阶段立即刷一批；阶段切换重置刷怪计时，不清除存量敌人。种类从允许列表随机选择，重复条目增加权重；数量为 0 或列表为空时不生成。

| 默认阶段 | 持续世界秒 | 每批 | 间隔世界秒 | 种类 |
|---|---:|---:|---:|---|
| 入阵 | 25 | 2 | 3.0 | 双斜射手 |
| 交锋 | 35 | 3 | 3.0 | 射手、棱镜 |
| 游猎 | 40 | 3 | 2.7 | 棱镜、猎手 |
| 脉冲 | 45 | 4 | 2.4 | 全部 |
| 压力 | 35 | 5 | 2.2 | 全部 |
| 喘息 | 8 | 0 | 2.0 | 不生成 |
| 极限 | 60 | 5 | 1.8 | 全部 |

默认最后阶段持续执行；关闭“结束后持续最后阶段”则整个列表结束后停止刷新，已有敌人仍活动。时间折叠延缓阶段推进，回溯恢复当时的阶段。压力与休整是可调节奏设计，不代表已经通过心流验证。

## 反馈规范

| 当前斩击击杀数 | 名称 | 每杀碎片 | DOTween 镜头位移震幅 | 震动秒数 | Vignette 亮角强度 |
|---|---|---:|---:|---:|---:|
| 1–2 | 破阵 | 64 | 0.10 | 0.140 | 0.16 |
| 3–4 | 连破 | 110 | 0.18 | 0.205 | 0.27 |
| 5–6 | 狂斩 | 180 | 0.28 | 0.270 | 0.40 |
| ≥7 | 极斩 | 280 | 0.40 | 0.335 | 0.55 |

Particle System 径向碎片、扩散冲击环、玩家形变、Bloom 爆闪及连斩音高共同提升。DOTween 直接驱动 Main Camera，棋盘和 Canvas Transform 不参与震动，完成后恢复基准位置；Cinemachine 写入已停用，避免冲突。Vignette 使用 HDR 青色 `(1.5,12,8)` 产生真实亮角，普通 ≤1 颜色只会压暗。连斩峰值保留约 0.8 秒余韵后衰减。

深色背景、青色玩家、红紫黄粉敌人，形状区分类型；技能特效保留敌人轮廓。UI 沿用用户排版，按钮悬浮与点击使用 DOTween。程序合成音乐从 92 向 142 BPM 递增，25/65 秒增加声部；击杀、收刀、选择、折叠、倒带、死亡使用不同音效。最终听感需试听。

## 教学与页面

`MainMenu` 提供进入棋盘及新手引导；`BlockNight` 承载战斗、七步教学、暂停与强化；`GameOver` 展示成绩、重开与返回主界面。三者均为独立保存的场景。教学与战斗共用规则：转向→走格→斩击→折叠→等待释放→回溯→正式战斗；教学暂停自然刷怪与攻击，可随时跳过。

验收结果及待真人确认项见《验收报告》，编辑入口见《使用与微调》。
