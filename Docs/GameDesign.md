# 方块战士 · 午夜暗房

版本 0.2 · 2026-09-08。以实际试玩反馈重构，取代旧版“WASD一冲到底”的规则。旧版设计归档于 `Docs/Evidence/v1`。

## 一句话体验

在一张9×9的底片上逐格选线，用冲斩切开整列游影；凝时保留一串待显影的死亡，松开的时间将它们一起冲印出来；失手时，把整张底片倒回过去。

主题围绕暗房、底片、曝光、显影和磁带倒转，所有画面、界面、音色与机制名称都围绕这组意象建立关系。

## 操作与空间规则

| 输入 | 行为 |
|---|---|
| WASD / 方向键 | 只移动相邻一格，不攻击；按住可按固定节拍继续走格 |
| Shift | 朝当前面向冲至边界，沿途斩击 |
| Shift＋方向键 | 指定方向冲斩 |
| 空格 | 凝时 |
| Q | 回溯；死亡后也能使用 |
| 1 / 2 / 3 或鼠标 | 选强化 |
| Esc / M / Enter | 暂停 / 静音 / 确认开始或重开 |

- 9×9棋盘。玩家与敌人的逻辑位置都是整数格心（坐标−4到4），不允许自由连续走位或斜着穿格。
- 普通走格更新相邻格，约0.15秒收招；长按首次重复延迟0.26秒，之后约0.16秒一步。短按只能走一格。
- 视觉可以在相邻格间短暂插值，表现脚步而非瞬间闪现；插值不改变占格和碰撞规则。
- 冲斩约38格/秒，按经过的格线依次判定击杀；到边界收招0.13秒。冲斩中不能转弯。
- 普通移动不攻击，撞上已激活敌人死亡。冲斩能击杀敌人，但默认不能无视弹幕。扫掠检测防止快速穿过弹丸。
- 小三角表示面向，使单独按Shift的结果可预期。任意内部格都可以通过普通移动到达。

## 单局循环与目标

标题→首次交互练习（可跳过）→五分钟战斗→周期三选一→胜利或死亡→重玩。死亡时如Q可用，玩家可以先回溯再重选路线。

战斗目标是保住五分钟底片。分数提供连杀追求，成长进度提供下一个短期目标。没有局外养成或额外生命，保留一击死亡与主动选线的识别度。

第n个连杀敌人基础分为 `100×[1+0.35×(n−1)]`，每项取整。普通冲斩各自计连杀；同一次凝时的悬置击杀在释放时按总数计算。

## 凝时：待显影 → 释放

持续3.2秒，世界速度×0.06，冷却12秒（从施放起计）。玩家走格与冲斩保持正常速度；敌人步进、出生计时、攻击、弹幕都显著滞后。局时、成长与技能持续时间按正常战斗时间计算。

凝时期间切中的敌人保留在原格，变成冷青曝光轮廓，不再移动或攻击；不立即发分，也不立即死亡爆炸。短暂浮字显示待显影数量。凝时结束统一结算，出现显影扩散环、纸屑般碎片、快门重音、75ms模拟卡顿与短促震动。

画面从墨黑/朱红切到冷青近单色负片：低饱和、高对比、色彩滤镜、色差、轻微镜头形变与更明显的曝光光晕共同作用。音乐主声部降至约15%电平、音高/速度降至0.28、低通到约380Hz，叠加独立的持续凝滞低音。释放时凝滞层收掉，主乐恢复。

慢时结束边界帧的新命中使用正常击杀，不能遗留无法释放的悬置敌人。

## 回溯：整张底片倒回

回到3.5秒前，0.95秒播放完整历史，冷却22秒。至少记录0.6秒后才可施放，死亡后保留使用机会。结束有0.65秒保护，以允许新选择。

按20Hz保存最多105份深复制快照：玩家格心/面向/冲斩进度，全部敌人格心/步进目标/出生与攻击状态，弹幕，凝时与待显影对象，积分/斩杀统计，局时/成长/刷新计时，随机状态。倒带逐步恢复这些内容，不能仅传送玩家。

技能冷却与强化等级不回滚，技能动画期间也不获免费冷却。选定强化后清除旧历史形成检查点，不能回溯重选或复制收益。回溯撤销的积分必须重新挣取。

视觉使用紫灰染色、反向扫描、拖影与镜头扭曲；声音使用磁带倒卷扫频，主乐临时退场，与凝时的“持续悬停”区分。

## 敌人与预警

| 敌人 | 轮廓与色彩 | 规则 | 首次出现 |
|---|---|---|---|
| 游影 | 朱红方块 | 每约1.65→0.8秒走一个相邻格，不能斜走；落点提前约0.3秒描边 | 开局 |
| 曝光眼 | 药液金圆形 | 留在格心，每2.5秒沿主轴发射；前0.8秒锁定射线 | 22秒 |
| 针影 | 铁锈橙三角 | 留在格心，每3.1秒发射高速直线弹；前0.8秒锁定射线 | 50秒 |
| 裂片 | 低饱和紫灰菱形 | 步进比游影慢30%；死后在空闲相邻格生成两个游影 | 90秒 |

敌人出生1.15秒以上预警，期间无伤害且不能提前斩杀；随机出生避开玩家1.5格与已占用格。裂片子体也要预警。追踪敌人只选一个轴、一个格；不能重叠占格。弹幕是飞行攻击，不是敌人单位，可以沿直线连续飞行。

敌人上限48；弹丸6秒或越界回收。对后期压力的主要调节是数量、混合机制与节拍，而不是取消预警。

## 肉鸽强化

每27秒获得一次三选一，击杀额外推进0.85秒。选牌冻结全部模拟和冷却；冲斩或凝时期间到点，延迟到动作结束。每次三个不同未满级选项，不足时提供2500分补偿。选完保护0.7秒。

| 强化 | 每级效果 | 上限 |
|---|---|---|
| 长曝光 | 凝时+0.7秒 | 3 |
| 快门回弹 | 凝时冷却−2秒，最低6秒 | 3 |
| 深层底片 | 回溯+0.5秒，冷却−2秒 | 3 |
| 净片 | 冲斩清掉沿途弹幕；清除半径0.4+0.2×等级 | 3 |
| 连拍 | 冲斩速度+18%，收招时间×0.85 | 3 |
| 叠影 | 连杀阶梯+15个百分点；每个额外连杀额外推进强化0.1×等级秒 | 4 |
| 显影扩散 | 凝时结算波及相邻格；高等级增加扩散击杀的连杀奖励 | 3 |
| 银盐回收 | 击杀推进强化额外+0.3秒，总分+15% | 4 |

路线：长曝光+显影扩散做积蓄清场；净片+连拍做主动穿越火线；叠影+银盐回收做成长加速。旧版“刀宽”改为净片，避免整数网格下小幅加宽无效的强化。

刷新间隔从2.4秒逐步缩到约0.65秒，每波2→5个。每44秒有一段35%间隔延长作为缓冲。凝时按世界时间减缓出生。五分钟完成，避免无尽模式超出基础机动承受范围。

## UI层级与引导

战斗视野以中央棋盘为绝对主体，顶端分数/倒计时，底端凝时/回溯的键位与状态，加一条成长细线。连杀与显影是短暂反馈，不常驻。游戏名称、敌人说明、全套操作、宣传语不堆在战斗HUD。

标题使用大中文标题、两行氛围文案与胶片齿孔/曝光方孔构图。选牌只有序号、强化名、实际效果和快捷键。暂停页放完整操作；结算页放统计。全中文显示，随包附带Noto Sans CJK SC字体及许可证。

首次练习四步，每次只显示当前提示：

1. 移动一格：实际走格后推进。
2. 冲斩：在固定列斩开四个目标后推进。
3. 凝时：先凝时再冲斩，看到待显影→实际释放后推进。
4. 回溯：走几格后Q，观察场景回退，完成后进入正式五分钟。

练习无随机出生与死亡；可以直接跳过，也可在暂停页重看。练习保护不进入正式局。

## 美术与声音约束

墨黑底、骨白主角、朱红危险、药液金点缀、紫灰回溯。敌人的几何轮廓重复出现在胶片/界面中。胶片颗粒只作为细微材质，不得影响格心、轮廓或文字；闪光与镜头形变仅在技能/释放短时出现。

声音分为磁带底噪、低频脉冲、快门打击、稀疏金属钟音四个同步声部。进度逐步加入更密的节奏和钟音；步进用干燥小咔嗒，冲斩用快门扫切，悬置命中用玻璃短音，释放用低频快门，回溯用倒卷，死亡用破片。所有音频当前程序生成，便于逐项调节和替换。

## 心流验收

自动测试负责规则与边界，不证明主观爽感或独特性。真实试玩至少5人，记录前三局首死时间、死亡原因、技能频率、对预警的理解和每分钟1–5分压力。目标：新玩家中位存活60–150秒，熟悉玩家三局内进入第4分钟，能理解凝时的积蓄释放与回溯的重选价值。依反馈优先调整预警/并发/节拍，而不是隐蔽加速。
