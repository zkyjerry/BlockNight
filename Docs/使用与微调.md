# 使用与微调

## 开始试玩

打开 `Assets/BlockNight/Scenes/MainMenu.unity`，按 Unity Play，从“进入棋盘”或“新手引导”开始。Build Settings 顺序已经设置为 MainMenu → BlockNight → GameOver。直接运行 BlockNight 也会开始正式局；直接运行 GameOver 时没有本局成绩，显示零值。

WASD 不同朝向只转身，同方向走一格；J 冲刺，空中 WASD 在下一格心转弯。拾取青色时间暂停道具后按 K 时间折叠，拾取紫色时间回溯道具后按 L 回溯；两类缓存合计最多 3 个，并显示在玩家身上。普通走格不能击杀，只有生效的危险格命中才致死。Esc 暂停，M 静音。

## 修改阶段刷怪

在 Project 选中 `Assets/BlockNight/Data/SpawnSchedule.asset`。Inspector 已提供中文面板：

1. “阶段数量”控制阶段列表长度，展开对应阶段。
2. 填写阶段名称、持续时间、每批敌人数、刷新间隔。
3. “允许敌人种类”可配置多个类型，列表中随机选择；重复项增加该类型权重。
4. 每批数量为 0 可制作休整。末尾勾选“结束后持续最后阶段”表示最后的规则永久继续，否则阶段全部结束后停止刷新。

阶段进入时立即刷新，之后按间隔刷新；使用世界时间，K 会减缓推进。新建另一套配置：Project → Create → Block Night → 阶段刷新配置，拖到战斗场景 `BLOCK NIGHT — systems` 的 GameDirector.spawnSchedule 字段。默认配置在设计文档中逐项列出。

编辑模式修改可持久保存。Play 中直接改 SO 也可能持久化到资产，试验前可复制一份配置。

## 修改单个敌人

打开 `Assets/BlockNight/Data/Enemies`，分别选择突进方卫、斜波棱镜、巡格猎手、逆波脉冲的 SO。中文 Inspector 可调整攻击间隔和预警，斜波型还可修改移动周期、传播格数和每格预警。方向使用格坐标，例如 `(1,1)` 为右上；撞击型规范为上下左右，波形规范为四个斜向。

敌人 SO 通过战斗场景 GameDirector 的 Enemy Definitions 数组绑定，顺序对应阶段列表中的四个类型。新建替代配置可使用 Create → Block Night → 敌人属性，再替换对应数组元素。修改某类属性不会覆盖其他类。

## 修改时间道具

选中 `Assets/BlockNight/Data/Balance.asset`：

- `Max Charges`：暂停与回溯共用的缓存上限，当前为 3。
- `Item Interval`：每次刷新判定的世界时间间隔，当前为 4.5 秒。
- `Item Chance`：每次判定实际生成道具的概率，当前为 0.35。
- `Rewind Pickup Share`：成功生成时选为回溯道具的概率，当前为 0.5；其余为暂停道具。

道具外观分别编辑 `Prefabs/Items/时间暂停.prefab` 和 `时间回溯.prefab`。场上实例位于 `ITEMS — instantiated`，由运行时按模型状态创建和销毁；不要把实例手工保存到该节点。

## 数值与视听入口

| 调整内容 | 位置 |
|---|---|
| 冲刺、走格速度；技能持续、道具刷新与缓存上限；强化计时 | `Data/Balance.asset` |
| 敌人攻击、移动、预警与格子冲击波 | `Data/Enemies/*.asset` |
| 每阶段时间、数量、种类和间隔 | `Data/SpawnSchedule.asset` |
| 连斩分档碎片数量、摄像机震幅和亮角强度 | `Scripts/ArenaPresentation.cs` 的 Counts / Strengths / Corners |
| 各强化效果及积分公式 | `Scripts/CombatModel.cs`；配套文案在 GameHUD.cs |
| 棋盘、灯光、玩家 Prefab 实例、格子攻击池 | `Scenes/BlockNight.unity` 的世界层级 |
| 四类敌人与两类道具外观 | `Prefabs/Enemies/*.prefab`、`Prefabs/Items/*.prefab` |
| Bloom、Vignette、色差、颜色调整 | Presentation 引用的 Volume Profile；运行时脚本按技能与连斩覆盖强度 |
| 字体 | `Fonts/FZXS12 TMP.asset`，动态 SDF、多图集，源字体为用户提供的 FZXIANGSU12.TTF |
| 主菜单与失败页布局 | 分别打开 MainMenu.unity、GameOver.unity |
| 战斗 HUD、强化、暂停、教程 | BlockNight.unity → HUD — editable canvas |

所有 35 处文字均为 TextMeshProUGUI，代码使用 TMP_Text 引用。静态文字直接在 Inspector 改；每帧刷新的数字、教学、卡片和状态文字在 GameHUD / MenuController 中改。已保留用户原有 RectTransform、颜色、大小和节点；仅为字体迁移调整小号文字行距。

四类敌人通过 `ArenaPresentation` 从 `Prefabs/Enemies` 实时 Instantiate 到 `ENEMIES — instantiated`；两类道具同理进入 `ITEMS — instantiated`。玩家使用 `Prefabs/Player/玩家.prefab`，Prefab 实例直接保存在棋盘场景中，包含朝向、Light2D 和三个缓存标记。格子攻击仍使用场景预置池，棋盘、灯光、粒子和护盾也继续作为可编辑场景对象保存。旧 `ENEMIES — 36 prebuilt slots` 已停用，仅作迁移遗留，不应重新启用。

扩展敌人时需同步 `EnemyKind`、EnemyDefinition、敌人 Prefab、`ArenaPresentation.enemyPrefabs` 与相关检查；扩展道具时同步 `PickupKind`、Prefab 数组、生成/消耗规则及缓存标记表现。

## 菜单文字

MainMenu 与 GameOver 已移除 TextAnimator 和 TextAnimatorPlayer 组件，不再调用 ShowText。保留安装的插件，后续可自行添加。所有文字继续使用 TMP 和指定像素字体，按钮原有 DOTween 悬浮、点击反馈保留。

## 复查与调试

Unity 菜单 `Block Night/QA/Run Grid v4 Checks` 可在编辑模式运行规则检查。先从主菜单进入战斗，再执行 `Run Runtime Checks`，验证 UI 绑定、七步教学、技能、强化、死亡状态和反馈。`Check v5 Presentation` 检查红色预警、非红色出生、圆形护盾及破盾粒子；在主菜单或失败页运行 `Check Static Menu` 检查完整静态 TMP 文字。运行检查会改动当前局，请退出并重新 Play 后试玩。

`Combat / Slow / Rewind / Draft Fixture` 用于固定截图；`Capture 1600x1000` 与 `Capture 1280x720` 保存截图到 `Docs/QA`。Fixture 会停用当前局自动推进，只用于表现检查。`Force Game Over` 用于验证跨场景统计与按钮。

`TMP`、`Apply v3` 和 `Grid v2` 菜单属于历史迁移工具，当前场景已迁移完成，不是日常构建入口。通常直接打开并编辑三个场景即可。v6 已应用；`Docs/Pending-v4` 仅保留中断时的历史暂存稿，不应覆盖后续编辑。迁移前备份及原文保留在 `Docs/Backups`。

## 人工试玩建议

连续试玩三局，记录每局生存时间、死亡原因、强化次数、最大连斩与两类道具拾取消耗次数。重点确认空中转向是否及时、3/5/7 杀反馈是否逐档明显、道具辨识是否清楚、三枚缓存标记是否易读，以及 K 的延迟爆发与 L 的倒带是否能凭视听分辨。优先通过刷怪 SO 和 Balance 道具参数调整压力；实际流畅度及音效舒适度由真人验收。

## 范围冲击波和最新反馈

选中 `Assets/BlockNight/Data/FeedbackSettings.asset`：

- `Upgrade Shockwave`：强化后冲击波开关。
- `Shockwave Radius`：最大半径（格），默认 4；包含圆周边界，范围外敌人不受影响。
- `Shockwave Seconds`：从玩家扩散到最大半径的时间，默认 0.65 秒。
- `Dying Seconds / Dying Vignette / Dying Color`：濒死窗口与深红后处理。
- `Focus Size / Focus Seconds / Restore Seconds`：Cinemachine 聚焦与恢复。
- `Ready Flash Alpha / Ready Flash Seconds`：成功拾取暂停/回溯道具时的青色/紫色闪光。

终点消散粒子在场景 `UPGRADE WAVE — dissolve particles`；波形为 `UPGRADE CLEAR — expanding wave`；边框计时为 `UPGRADE CLOCK — remaining CCW`，底轨是 `UPGRADE CLOCK — track`。以上都是已保存的世界对象，可在场景直接微调。旧顶部横条已隐藏，顶部数字保留。新闪光 Canvas 不阻挡鼠标操作。

`Run Wave Radius Checks` 验证范围内外、边界、奖励、回溯及终点粒子；`Run v6 Feedback Checks` 验证镜头、红框增长、计时环和拾取闪光；`Wave Endpoint Fixture` 可查看圆环化为粒子的瞬间。上述 QA 会改动当前测试局，结束后重新 Play 再试玩。

当前 Balance 中冲刺速度为 11、强化周期为 60 秒；刷怪表保留用户调整，没有恢复旧默认值。字体若以后重新出现缺字，可在编辑模式执行 `Block Night/TMP/Repair Demo Glyph Atlas`，该工具保留字体和 UI 布局。
