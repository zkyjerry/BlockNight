# 使用与微调

## 开始试玩

打开 `Assets/BlockNight/Scenes/MainMenu.unity`，按 Unity Play，从“进入棋盘”或“新手引导”开始。Build Settings 顺序已经设置为 MainMenu → BlockNight → GameOver。直接运行 BlockNight 也会开始正式局；直接运行 GameOver 时没有本局成绩，显示零值。

WASD 不同朝向只转身，同方向走一格；J 冲刺，空中 WASD 在下一格心转弯；K 时间折叠，L 回溯。普通走格不能击杀，只有弹幕命中才致死。Esc 暂停，M 静音。

## 修改阶段刷怪

在 Project 选中 `Assets/BlockNight/Data/SpawnSchedule.asset`。Inspector 已提供中文面板：

1. “阶段数量”控制阶段列表长度，展开对应阶段。
2. 填写阶段名称、持续时间、每批敌人数、刷新间隔。
3. “允许敌人种类”可配置多个类型，列表中随机选择；重复项增加该类型权重。
4. 每批数量为 0 可制作休整。末尾勾选“结束后持续最后阶段”表示最后的规则永久继续，否则阶段全部结束后停止刷新。

阶段进入时立即刷新，之后按间隔刷新；使用世界时间，K 会减缓推进。新建另一套配置：Project → Create → Block Night → 阶段刷新配置，拖到战斗场景 `BLOCK NIGHT — systems` 的 GameDirector.spawnSchedule 字段。默认配置在设计文档中逐项列出。

编辑模式修改可持久保存。Play 中直接改 SO 也可能持久化到资产，试验前可复制一份配置。

## 数值与视听入口

| 调整内容 | 位置 |
|---|---|
| 冲刺、走格速度；技能持续与 CD；强化计时；出生预警 | `Data/Balance.asset` |
| 每阶段时间、数量、种类和间隔 | `Data/SpawnSchedule.asset` |
| 连斩分档碎片数量、摄像机震幅和亮角强度 | `Scripts/ArenaPresentation.cs` 的 Counts / Strengths / Corners |
| 各强化效果及积分公式 | `Scripts/CombatModel.cs`；配套文案在 GameHUD.cs |
| 棋盘、灯光、玩家、预置敌人/弹幕池 | `Scenes/BlockNight.unity` 的世界层级 |
| Bloom、Vignette、色差、颜色调整 | Presentation 引用的 Volume Profile；运行时脚本按技能与连斩覆盖强度 |
| 字体 | `Fonts/FZXS12 TMP.asset`，动态 SDF、多图集，源字体为用户提供的 FZXIANGSU12.TTF |
| 主菜单与失败页布局 | 分别打开 MainMenu.unity、GameOver.unity |
| 战斗 HUD、强化、暂停、教程 | BlockNight.unity → HUD — editable canvas |

所有 35 处文字均为 TextMeshProUGUI，代码使用 TMP_Text 引用。静态文字直接在 Inspector 改；每帧刷新的数字、教学、卡片和状态文字在 GameHUD / MenuController 中改。已保留用户原有 RectTransform、颜色、大小和节点；仅为字体迁移调整小号文字行距。

敌人及子弹使用场景预置池，运行时切换显示并更新位置，不通过一个脚本临时生成整套场景。增大池容量时需同步模型上限和 Presentation 数组。扩展敌人时同步类型枚举、形状、颜色、AttackDirections 与相关检查。

## 复查与调试

Unity 菜单 `Block Night/QA/Run Logic Checks` 可在编辑模式运行规则检查。先从主菜单进入战斗，再执行 `Run Runtime Checks`，验证 UI 绑定、七步教学、技能、强化、死亡状态和反馈。运行检查会改动当前局，请退出并重新 Play 后试玩。

`Combat / Slow / Rewind / Draft Fixture` 用于固定截图；`Capture 1600x1000` 与 `Capture 1280x720` 保存截图到 `Docs/QA`。Fixture 会停用当前局自动推进，只用于表现检查。`Force Game Over` 用于验证跨场景统计与按钮。

`TMP`、`Apply v3` 和 `Grid v2` 菜单属于历史迁移工具，当前场景已迁移完成，不是日常构建入口。通常直接打开并编辑三个场景即可。迁移前备份及原文保留在 `Docs/Backups`。

## 人工试玩建议

连续试玩三局，记录每局生存时间、死亡原因、强化次数、最大连斩。重点确认空中转向是否及时、3/5/7 杀反馈是否逐档明显、K 的延迟爆发与 L 的倒带是否能凭视听分辨。优先通过刷怪 SO 调整压力，再改技能 CD；实际流畅度及音效舒适度由真人验收。
